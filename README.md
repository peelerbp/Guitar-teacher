# Guitar Practice Coach — PWA

This is a Progressive Web App version of the guitar practice prototype.

## Use it
The app must be served over HTTPS (or localhost) for the service worker and install-to-home-screen features to work.

After it is hosted:
1. Open the site in Safari/Chrome.
2. Use the browser's Share/Add to Home Screen option.
3. Launch Guitar Practice Coach from the Home Screen.

## Current features
- Chord selection
- 40–200 BPM
- Tap tempo
- Beats per chord
- Ordered/random progression
- Session timer
- Audible metronome
- Current/next chord
- Chord diagrams
- Offline caching after first load

Next planned module: scale practice + interactive guitar fretboard.
